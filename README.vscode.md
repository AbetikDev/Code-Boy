## 🌟 What is Code Boy?

**Code Boy** brings warmth, charm, and gamified motivation to your development environment. Living quietly in your VS Code sidebar, Code Boy is an interactive pixel-art developer companion inspired by classic virtual pets (Tamagotchi) and cozy retro games.

He observes your active coding sessions in real-time and reacts to your editor activity:
- **He clatters on his keyboard** when you type.
- **He sips warm coffee** when you pause to read or think.
- **He wears headphones and bobs his head** when music plays.
- **He scratches his head** when linters or compilers flag warnings and errors.
- **He celebrates with confetti** when builds pass and bugs are resolved.
- **He falls asleep peacefully** when you step away for a break or call it a night.

Everything runs **100% offline and locally**. No code, prompts, or personal data ever leave your machine.

## 📥 How to Install

### Option A: From VS Code Extensions View (Recommended)
1. Open **Visual Studio Code**.
2. Press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS) to open the **Extensions** view.
3. In the search box, type **Code Boy**.
4. Click **Install**.

### Option B: Install from VSIX Package
If you have downloaded the `.vsix` file directly:
1. In VS Code, open the Extensions panel (`Ctrl+Shift+X`).
2. Click the `...` (Views and More Actions) menu in the top right corner.
3. Select **Install from VSIX...** and choose your `code-boy-1.0.0.vsix` file.
*Alternatively, install via terminal:*
```bash
code --install-extension code-boy-1.0.0.vsix
```

## 🕹️ How to Use

1. **Locate Code Boy**:
   - Open your **Explorer Sidebar** (`Ctrl+Shift+E`). Code Boy is docked at the top or bottom panel.
   - Or click the **ContextBack** icon in the left Activity Bar.
2. **Start Coding**:
   - Open any file and type. Code Boy automatically wakes up and mirrors your activity!
3. **Interact with Code Boy**:
   - **Click**: Pet Code Boy to give him love, boost his mood, and trigger happy hearts.
   - **Right-Click / Long-Press**: Opens the quick action menu (Pet, Dance, Vibe Mode, Sleep, Change Room, View Stats).
   - **Level Badge**: Click the `LV.` badge in the top header to view detailed XP and stats.

## ⌨️ Command Palette Actions

Press `Ctrl+Shift+P` (or `Cmd+Shift+P`) and type `Code Boy`:

| Command | Description |
| :--- | :--- |
| `Code Boy: Open` | Focus and show Code Boy in the sidebar |
| `Code Boy: Pet` | Give Code Boy some appreciation |
| `Code Boy: Dance` | Trigger an energetic celebratory dance |
| `Code Boy: Toggle Vibe Mode` | Toggle headphones and chill music vibes |
| `Code Boy: Change Room` | Switch between unlocked cosmetic room backdrops |
| `Code Boy: Show Stats` | View developer vitals, XP progress, and streaks |
| `Code Boy: Sleep / Wake Up` | Put Code Boy to sleep or wake him up |
| `Code Boy: Connect Spotify` | Pair your Spotify account for track syncing |
| `ContextBack: Continue Session` | Instantly restore your previous coding context |
| `ContextBack: Summarize Session`| View changes, branch status, and open TODOs |

## ⚙️ Settings & Customization

Open VS Code Settings (`Ctrl+,` or `Cmd+,`) and search for `Code Boy` to customize:

| Setting | Default | Description |
| :--- | :--- | :--- |
| `codeBoy.enabled` | `true` | Enable or disable Code Boy companion and tracking |
| `codeBoy.soundEnabled` | `false` | Enable nostalgic 8-bit sound effects on interactions |
| `codeBoy.roomTheme` | `DEFAULT` | Set your default room backdrop |
| `codeBoy.vibeMode` | `false` | Always keep Vibe Mode active with headphones |
| `codeBoy.musicDetection` | `true` | Automatically detect playing music and animate notes |
| `codeBoy.animations` | `true` | Enable sprite animations and particle effects |
| `codeBoy.idleAnimations` | `true` | Enable subtle idle behaviors (reading, coffee sipping) |
| `codeBoy.animationSpeed` | `1.0` | Adjust animation speed from 0.5x to 1.5x |
